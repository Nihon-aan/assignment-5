What is the difference between var, let, and const?

=>  var declares a variable that can be redeclared and reassigned. let declares a variable that can be reassigned but not redeclared in the same scope.
const declares a variable that cannot be reassigned or redeclared.


What is the spread operator (...)?

=> The spread operator is used to expand elements of an array or properties of an object into individual elements or properties.


What is the difference between map(), filter(), and forEach()?

=> map() creates a new array by transforming each element of the original array. filter() creates a new array containing elements that pass a given condition.
forEach() executes a function for each array element but does not return a new array.


What is an arrow function?

=> Arrow function is a shorter way to write functions in JavaScript using the => syntax.


What are template literals?

=> Template literals is a way to write strings using backticks (`) and easily include variables.
